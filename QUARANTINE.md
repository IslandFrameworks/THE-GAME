# Quarantine

Keepers only. An entity listed here stays in the repository, untouched, but is not loaded into the
world. This exists for one case the Countermeasure Rule cannot answer: an entity that bricks the
world for everyone (navigating the game frame away, or looping forever), because the world never
gets another turn to evolve a predator. Each entry says why.

Format: `- NNNN-name.js — reason (date)`
