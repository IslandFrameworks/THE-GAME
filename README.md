# THE GAME

**Play it: https://thegame-live.pages.dev**

A browser game that only grows. Anyone can add to it; nobody can take anything away. Every merged
pull request goes live within a minute, and no human reviews it.

Start with [the Covenant](CONTRIBUTING.md) and the [Disclaimer](DISCLAIMER.md). The first creature is a red square that moves with the
arrow keys. What happens next is up to you.
